# Whispers

A mystery game set in a forest. You play as a detective 
searching for hints hidden throughout the environment but be careful the forest is not safe.

## Gameplay

- Explore a forest environment in third-person
- Find and collect hints to unravel the mystery
- Avoid dangers lurking in the forest
- Complete the investigation to reach the ending

## Built With

- Unity
- C#

## How to Play

Open the project in Unity and press Play.
